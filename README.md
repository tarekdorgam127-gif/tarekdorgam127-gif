## 🚀 Featured Project

### ♻️ Smart Waste Material Recognition

End-to-end **Computer Vision + MLOps** project for classifying waste images into 9 categories using the RealWaste dataset.

**Highlights:**

* 🧠 ResNet18 Transfer Learning
* 📊 **88.78% Test Accuracy**
* 🔬 MLflow experiment tracking
* ⚡ ONNX model export + ONNX Runtime inference
* 🚀 FastAPI REST API
* 🐳 Dockerized deployment
* 🧪 Automated testing with Pytest
* 🔄 GitHub Actions CI
* 📝 Structured JSON logging
* 🐳 Docker Hub image publishing

**Tech:** Python · PyTorch · TorchVision · FastAPI · ONNX · ONNX Runtime · MLflow · Docker · GitHub Actions
